# Data source

Download `AB_NYC_2019.csv` from Kaggle:

https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data

Save it in this `data/` folder. The dataset file itself is not included in this repo.

The file has 48,895 rows (one per listing) and 16 columns. It is a 2019
snapshot of Airbnb listings in New York City.
